# Word Decoder

A Python-based program that can encrypt and decrypt words using the Caesar cipher.

## Features:
- Validates user input for selection, encryption and decryption.
- Encrypts word using the Caesar cipher.
- Decrypts word using different numbers of shifts.
- Handles wrap-around in the alphabet.
- Exits loop if the user's input = exit or quit

## What I learned:
- While loops
- For loops
- Using 'ord()' and 'chr()' for ASCII codes
- Defining functions
- Using 'try' and 'except' for error handling
